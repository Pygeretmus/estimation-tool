# estimation-tool
Django app for configurable project estimates: platforms, option categories and priced choices.

## Setup
Install Docker at your device

## Project launch
Use your terminal

```sh
$ docker-compose -f docker/docker-compose.yml up --build

django-1  | Django version 5.1.7, using settings 'Radity.settings'
django-1  | Starting development server at http://0.0.0.0:8000/
django-1  | Quit the server with CONTROL-C.
```
